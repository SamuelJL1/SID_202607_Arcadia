# SID-Proyecto

## Arcadia

Este repositorio contiene el diseño y documentación de un sistema de información orientado a la **gestión de bibliotecas de juegos en Steam**.  
El sistema busca resolver la necesidad de los usuarios de organizar y administrar su colección de juegos, registrar el tiempo de juego y llevar un control de los logros alcanzados.  

El objetivo principal es **diseñar una base de datos** que soporte estas funcionalidades y permita generar reportes relevantes, tales como:  
- Tiempo de juego por usuario y por periodo.  
- Logros alcanzados vs pendientes en cada título.  
- Listado de juegos más jugados dentro de cada biblioteca.  

En conjunto, este sistema pretende mejorar la experiencia de los usuarios al darles una visión clara y estructurada de su actividad en la plataforma.
